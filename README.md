# 🐦 Flappy Bird — Java

A simple 2D Flappy Bird-style game built using **Java Programming".

## ✨ Features

- 🐦 Player-controlled bird
- 🪽 Gravity-based bird movement
- ⬆️ Jump mechanic using keyboard input
- 🟩 Randomly generated pipe obstacles
- 💥 Collision detection
- 🏆 Score tracking
- 🎮 Keyboard event handling
- 🔄 Continuous game loop
- 🖼️ Custom game graphics
- 🪟 Java Swing game window

🎮 Controls
Key	Action
SPACE	Make the bird jump
SPACE	Restart / interact depending on game state
